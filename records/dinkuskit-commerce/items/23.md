## Summary

Keep this PR open: its compensating rollback can overwrite a newer successful price update when a concurrent save's stock-status write fails.

Make the combined price-and-status save atomic, or add a versioned compare-and-set rollback that cannot overwrite a later price write, with an interleaving regression test.
