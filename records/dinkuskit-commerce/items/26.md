## Summary

Keep this PR open: its concurrent-disable protection still allows Configure Inventory to contact the provider after a clerk has disabled Manage stock, so the stated no-Inventory-on-disable behavior is not yet guaranteed.

## Best Possible Solution

Serialize cancellation with the registration side effect so a successful disable either prevents provider registration or is refused until the in-flight registration reaches a safe terminal state.
