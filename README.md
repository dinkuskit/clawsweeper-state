# clawsweeper-state

Public ClawSweeper review state for DinkusKit repositories

## Canonical record service

The prepared [canonical state service](docs/canonical-state-service.md) lives in
`service/`. It provides the current ClawSweeper record-publication protocol for
the five priority DinkusKit repositories. Deployment and writer cutover are
separate owner-approved steps; the existing Git reports remain intact.
